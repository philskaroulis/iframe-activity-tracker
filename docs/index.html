iframe Activity Tracker

Production-ready activity monitoring system for embedded iframes

Overview

A comprehensive solution for detecting and tracking user engagement within embedded iframes. Features security validation, rate limiting, and extensible event handling.

Quick Start

Include the minified script in your iframe:

<script src="https://philskaroulis.github.io/iframe-activity-tracker/oreilly-messages.min.js"></script>

Features

  • Real-time Activity Detection — Click, keypress, scroll, mouse movement, visibility changes
  • Live Countdown Timer — Shows milliseconds until next inactivity status update
  • Color-coded Status — GREEN (ACTIVE) / GRAY (INACTIVE) with timestamps
  • Message Validation — Origin check, source verification, event type validation
  • Error Handling — Try-catch wrapper prevents silent failures
  • Rate Limiting & Circuit Breaker — Auto-limits damage from malicious/spamming iframes
  • Timestamp Validation — Detects clock skew with configurable tolerance
  • Extensible Event Handlers — Register custom handlers for any event type
  • Debug Mode — Toggle verbose logging for troubleshooting
