Activity Monitor POC

This page monitors user activity in the iframe below. Try clicking, typing, scrolling, or moving your mouse inside the iframe.

How This Works

Parent Page (this page): Uses parent-library.js to listen for messages from the iframe and tracks user activity. When activity is detected, the header turns green (ACTIVE). After 15 seconds with no activity, it turns gray (INACTIVE).

Iframe: Uses iframe-messages.js to detect user events (click, keydown, scroll, mousemove, visibilitychange) and sends them to the parent page using window.parent.postMessage().
